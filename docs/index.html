01 What exactly this is

Not a feed for the internet.
A forum with a closed door.

Only people who share a campus get in. That constraint is the whole point — it's why a question here gets an answer, and why an announcement here is actually read.

01

One shared feed

Event notices, lost-and-found, project teams, study partners. Newest first — no algorithm deciding what you get to see.

02

Communities that map to real life

Computer Science, Campus Life, Research Hub, Tech Club. Join the ones you belong to, or create the one nobody has made yet.

03

Profiles that carry weight

Department, bio, resume link, GitHub and LinkedIn attached to your name — so you arrive with context, not a blank slate.

04

Small on purpose

No strangers, no engagement bait, no infinite scroll for its own sake. The audience is already the right size, so it stays worth reading.

02 Who can use it, and why

Built for everyone
who shares this campus.

Students

Find study partners before the exam, ask the question you've been holding since lecture, and catch the event notice before the WhatsApp forward reaches you.

Faculty & TAs

Post it once, in public, where it stays searchable. Fewer repeat questions, fewer announcements re-typed into five different groups.

Clubs & departments

Own a community instead of borrowing a chatroom. Your members are the people who actually opted in, and they can find the old post later.

Admins

One official surface for the whole campus. Anything that goes up stays up, in order, with an author — instead of vanishing with the chat.

Why?

Because campus information dies in private chats. It scrolls away, it gets screenshotted without a date, and the person who needed it most never saw it. Putting it in one searchable, public thread costs nothing and fixes almost all of it.

03 Under the hood

The stack behind VIT Connect.

React and TypeScript on the front, Firebase doing identity and storage, Tailwind for the interface, Vercel for delivery. Nothing here needs a server of its own.

Frontend

React 18

Component UI, client-side routing with React Router

Language

TypeScript

Typed models for User, Post, Comment, Community

Build

Vite

Instant dev server, one-command production build

State

Zustand

Single store for posts, communities, users, search

Styling

Tailwind CSS

Utility-first layout, responsive down to small screens

Auth

Firebase Auth

Email + password, plus one-tap Google sign-in

Database

Cloud Firestore

users / posts / communities collections, live queries

Hosting

Vercel

SPA routing, CDN edge delivery — this page is on GitHub Pages

Open source. Frontend and Firebase config in the repository — contributions welcome.
